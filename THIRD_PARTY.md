# Third-party sources

Icon Meta consumes metadata from upstream icon projects. Review upstream licensing and brand guidelines before redistributing artwork or using trademarks.

- Font Awesome Free: https://github.com/FortAwesome/Font-Awesome
- Devicons: https://github.com/devicons/devicon
- Simple Icons: https://github.com/simple-icons/simple-icons
- Octicons: https://github.com/primer/octicons

The generator is intentionally focused on metadata and CSS/runtime references rather than copying provider SVG artwork into this repository.
